# SVV Lab Task: Static Verification of C++ Code

## Project Overview

This project reviews a small text based monster battle game written in C++. The purpose is to identify programming defects through static code verification.

## Task 1: Review Checklist

The checklist covers eight categories:

1. Initialization
2. Pointer Null Detection
3. Arrays and Buffers
4. Loops
5. Arithmetic
6. Control Flow
7. Function Calls
8. Classes

## Task 2: Code Review Report

The report lists the line number, defect type, reason the defect is a problem, proposed solution, and severity.

## Project Files

- `game.cpp`: Original C++ source code.
- `Task1_Checklist.md`: Review checklist and results.
- `Task2_Code_Review_Report.md`: Detailed code review report.

## Conclusion

Static verification helps identify potential errors before program execution. Reviewing these defects improves code safety, reliability, and correctness.
